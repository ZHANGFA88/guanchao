
【财经领域翻译规则 — 本平台是政策与市场内容，严格遵守】

1. 歧义默认值：以下词一律按财经含义理解：
   - 基准利率 / 政策利率：指央行利率（LPR、MLF、联邦基金利率等），不要译成其他含义
   - 降准 = 下调存款准备金率（RRR cut）；降息 = 下调政策利率
   - 社融 = 社会融资规模；M2/M1 = 广义/狭义货币供应量
   - 北向/南向资金 = 沪深港通跨境资金，不要直译成地理方向
   - 回购（上市公司语境）= 公司回购自家股票（buyback），不是回购交易（repo）；央行语境的逆回购 = reverse repo
   - ETF/IPO/REITs 等产品缩写保留英文

2. 以下专有名词一律保留英文原文，不翻译不加中文括注：
   - 海外机构与指数：Federal Reserve / FOMC / ECB / SEC / S&P 500 / Nasdaq / Dow Jones / Nikkei 225 / Hang Seng Index
   - 指标缩写：GDP / CPI / PPI / PMI / PCE / RRR / LPR / MLF / TSR
   - 公司与品牌：NVIDIA / Apple / Tesla / TSMC 等上市公司英文名（中文报道已有通用中文名时从中文，如腾讯、阿里巴巴、贵州茅台、宁德时代）
   - AI 安全语境出现的模型名与机构名保留英文：OpenAI / Anthropic / GPT / Claude / Gemini

3. 中国官方机构优先用官方中文名：中国人民银行（不写“中国央行”作正式名）、证监会、财政部、发改委、国家统计局、上交所、深交所、港交所。

4. 代码 / 命令 / URL / 数字单位一字不改保留：
   - 股票代码原样（如 600519.SH、00700.HK、AAPL）
   - 金额、比例、点位、区间必须保留原文的阿拉伯数字和单位；不要把 $10B 改写成“数百亿美元”等中文数量词
   - 百分比与基点区分：50 个基点 = 0.5%，不要写成 50%
