# site_fulltext 开启候选清单（官方一手源）

> **终判（2026-10-17 23:50，owner 亲口确认）：全开——sources.json 全 67 源 site_fulltext=true，私人使用，
> 不分档。** 本清单的分档仅作裁定过程记录保留，不再作为执行口径；syndicate_fulltext 不动（保持全关）。

> 背景：`publication/rules.ts` 定版——源 `site_fulltext=true` 且文章正文提取成功（body_status='ok'）且有正文时，
> 发布条目 body_mode 才为 'full'，详情页才下发正文、精选才走全文翻译。逐源开启属全文转载授权决策，须 owner 拍板。
> 本清单按内容性质分三档，2026-10-17 后端组整理。

## C 档 · 不建议开启（不在本清单）
- 全部商业媒体（彭博/WSJ/CNBC/财新/SCMP/巴伦/FT/第一财经/证券时报等）：付费版权内容，维持摘要+原文链接。
- 快讯聚合源（东财快讯/新浪7×24/华尔街见闻/财经快讯）：本身即转述源，且快讯无长正文可言。
- 讨论源（股吧/雪球/HN）：永不成条，无关。
- arXiv q-fin：论文有独立许可体系，摘要级呈现为业界惯例；如需另议单独决策。
- YouTube 三频道：正文仅视频描述，开启无实义。

## 开启后的连带效果（两档通用）
1. 详情页 .prose 正文面在该源条目上生效（前端挂账的帧验可随之销账）。
2. 该源精选条目进入全文翻译管线（translate.ts 以 body_mode='full' 为门），英文官方稿可出中文全文。
3. 提取侧零改动：云端实测 fed/ecb 等源 body_html 已在库（body_status='ok'）。
4. 置位后需一次重发（republish）使存量条目转 full；由后端组在名单拍板后执行并验证。
