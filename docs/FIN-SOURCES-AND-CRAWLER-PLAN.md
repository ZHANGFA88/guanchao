## C. 爬虫学习计划（第 1 段）

目标：把现有「四路升级链」（普通请求 → curl_cffi 指纹 → StealthyFetcher → DynamicFetcher）从经验脚本升级为可诊断体系。按审批节流：学习与实测攒批进行，复用 cloudrun/Manus 既有路线。

1. **反爬新形态补课**：TLS/JA4 指纹演进、HTTP/2 指纹、DataDome/Akamai Bot Manager/PerimeterX 的挑战形态与识别信号、Cloudflare Turnstile 与 JS Challenge 的区别处置；产出：各形态的「失败指纹表」（状态码/响应头/页面特征 → 判型）。
2. **Scrapling 进阶**：adaptive 模式（DOM 结构变化后元素自适应重定位）、Fetcher 会话复用与指纹一致性（UA/TLS/时区/语言四件套一致）、patchright 与 Camoufox 的适用边界对照（雪球预热流程复盘）。
3. **及时性优化**：RSS 条件请求（ETag/Last-Modified，框架 rss-conditional 已有测试覆盖，核实全源启用面）、自适应轮询间隔（adaptIntervals 已有，核高频源参数）、News Sitemap 与 WebSub 评估、快讯类 api 源的长连接/短轮询取舍；目标：快讯级源端到端时延可测、可报。
4. **失败自诊断**：给推送器与 collect 加失败分类口径（DNS/连接、403 指纹墙、挑战页、200 空解析、结构变更、限流 429）——先在学习笔记里定分类表与每类处置（退避/换路/报警/人工），实现另行立项经架构审。
5. **58 源脆弱点清单（摸底初判，实测复核）**：
   - push 单脚本依赖：16 个 external 源全押 push-scrapling.py + 仓外 cron，单点（已知，S2 结构项）。
   - 雪球：cookie 预热（xq_a_token）脆弱，Camoufox/patchright 环境敏感。
   - 巴伦/SCMP：dj 系与 Cloudflare 墙，403 已实证待 curl_cffi 级复验。
   - page 模式 7 站（第一财经/财新/证券时报/每经/FT中文/21世纪/经观）：DOM 改版即空解析，需结构变更报警（与 4 联动）。
   - 华尔街见闻 lives API：接口字段变更无备用解析。
   - finflash：依赖 fusion-office serve 在线，二手汇聚一跳时延（A3/A4 直采可解）。
   - RSS 直采面：无 ETag 的源全量拉取浪费且慢；个别源（经济学人等）付费墙只剩标题，与本站口径相容但要在源健康里标注。
6. **产出**：学习笔记落 docs/CRAWLER-STUDY.md（本计划为纲，实测批完成后回填结论）；脆弱点逐项给「补强/观察/接受」建议，补强实现另行报架构立项，不在本单内顺手改代码。

## D. 第一批实测结论（2026-10-17 晚，云端真网络，架构放行批）

方法：普通请求直测各源公开接口/页面（云端 egress），逐源记状态/时延/样本；授权按架构硬规矩先核——不清者宁可不进。

| 源 | 结论 | 时延 | 证据/样本 | 授权结论 |
|----|------|------|-----------|----------|
| 新浪 7×24 直采 | ✅ 可抓 | 2.2s | zhibo/feed JSON 干净，样本为实时快讯（美联邦住房金融局局长发言条） | 公开快讯面，标题+摘要+链接口径相容 |
| 东财快讯直采 | ✅ 可抓 | 1.2s | getFastNewsList JSON，total 5000；首条即 SpaceX 相关（蓝色起源新格伦挑战 SpaceX） | 公开快讯面；只取标题/摘要字段，不抓正文页 |
| SEC EDGAR | ✅ 可抓 | 0.9–1.1s | browse-edgar atom（8-K 实时）+ efts 全文检索（q=SpaceX 命中 458 条）双通道均通；须带合规 UA 声明 | 美国政府公开，授权最清 |
| 港交所披露易 | ✅ 可抓 | 1.8s | 标题检索页是 JSF 壳，但 titleSearchServlet.do 直返 JSON（含 NEWS_ID/文件信息），样本为当日公告 | 官方公开 |
